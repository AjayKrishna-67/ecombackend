1. Setup

Start everything with bash static/test/razorpay-console/start.sh. It switches SMS, WhatsApp, email and the order webhook off, so a test order never messages a customer or the staff alert numbers. Use your own phone number below anyway.

Test customer (guest)

The email is generated per test (rzp-console+…@example.com) so guest checkout never collides with a real account.

Extra checkout steps this store needs (optional)

JSON list of {"query": "...", "variables": {...}}, run in the test customer's session after the shipping method is set (e.g. a delivery-slot mutation).

2. Scenarios

Each one creates a fresh cart, drives it, then checks the result against Vendure (admin API) and the stored webhook events. Webhook tests need the worker running. Razorpay test mode: pay with UPI success@razorpay, fail with failure@razorpay.
